# Frontend & Architecture

Vue / Nuxt を中心に、ユーザー向け Web アプリケーションの設計・実装をしています。

最近はプリセールス / アーキテクトとして、顧客課題の整理、クラウド構成、概算見積もり、提案書作成まで担当しています。

実装の現場感と、提案段階の抽象度を行き来しながら、作れるものを現実的な形に落とし込むのが得意です。

## What I Do

### Frontend Development

Vue / Nuxt / TypeScript を使った Web アプリケーション開発を中心に、画面設計、状態管理、多言語対応、アクセシビリティ、PWA などを扱っています。

ユーザーが直接触る機能では、外部 API の制約やブラウザ差異、表示パフォーマンスまで含めて調査し、実装方針に落とし込むことを大事にしています。

### Technical Leadership

チームのリードとして、要件定義、技術選定、見積もり、レビュー、進行管理を担当してきました。

認証や UI など再利用しやすい基盤を整え、案件ごとの初期開発コストを下げる取り組みもしています。テスト文化が薄いチームでは Vitest と TDD を導入し、品質を保ちながら実装を進める形を作りました。

### Architecture / Presales

顧客課題をヒアリングし、業務要件・予算・既存システムの制約を踏まえて、システム化方針やクラウド構成を提案しています。

AWS / Google Cloud を使った構成図、技術要件、非機能要件、概算見積もりを整理し、営業・PM・インフラ担当・開発メンバーと一緒に、提案を実現可能な形へ具体化しています。

## Featured Work

### Large Scale Visitor App

大規模イベント向けの来場者アプリで、会場マップ、現在地表示、施設・店舗検索、イベントカレンダーなどのフロントエンド開発を担当しました。

入社当初は不具合修正、アクセシビリティ対応、デザイン調整を中心に担当。その後、外部地図 API の制約調査、実現可否検証、新規機能の設計、顧客向けの実装方針提案まで担当範囲を広げました。

#### Scope

- 会場マップ、現在地表示、施設・店舗表示の設計・開発
- イベントカレンダーの設計・基盤実装
- PWA / Web Push 通知の技術調査・実装
- アクセシビリティ、多言語対応
- 結合テスト / システムテストのケース作成・管理
- リリース対応

#### Stack

TypeScript / Vue 3 / Nuxt 3 / Pinia / vue-i18n / 外部地図 API / GitHub / Figma / Backlog

### Internal Development Template

管理画面を中心とした社内開発テンプレートの立ち上げで、テックリード / フロントエンドリーダーを担当しました。

案件ごとに管理画面、認証、UI をゼロから作る課題に対して、認証基盤や UI を部分的に再利用できるテンプレートとしてスコープを定義。JWT 交換や PKCE フローを含む認証基盤を 6 週間で整備しました。

若手メンバーを含むチームをリードしながら、要件定義、技術選定、工数見積もり、開発、レビュー、進行管理を担当。実装済みの認証基盤を流用することで、顧客案件で想定されていた認証まわりの追加工数をほぼ不要にしました。

#### Scope

- 社内開発テンプレートの要件定義、設計、開発
- JWT / PKCE を含む認証基盤の設計・実装
- Vitest と TDD の導入
- 技術選定、工数見積もり、レビュー
- 若手メンバーの進行管理と育成
- 顧客案件への展開を見据えた再利用設計

#### Stack

TypeScript / Vue 3 / Nuxt 4 / shadcn/ui for Vue / Vitest / JWT / PKCE / GitHub / Backlog

### Proposal & Cloud Architecture

2025 年 8 月以降は、プリセールスエンジニア / アーキテクトとして、新規システム開発、生成 AI 活用、基幹システム刷新、公共領域の提案案件、自社 SaaS 提案などを担当しています。

初回商談で整理された課題をもとに、技術面のヒアリング、実現方式の説明、システム化方針の提案を実施。提案書では技術要件、アーキテクチャ、非機能要件、概算見積もりを主に担当しています。

生成 AI 活用では OCR や検索を用いた業務効率化案を検討。新規開発やシステム刷新では、AWS / Google Cloud を用いた構成、認証、データ連携、運用面を含めて実現性を整理しています。

OSS ベースの業務アプリ基盤を AWS 上に構築する提案では、構成検討、概算見積もり、提案方針の整理を行い、160 万円規模の案件獲得に貢献しました。

#### Scope

- 顧客ヒアリング、課題整理
- システム化方針の検討
- AWS / Google Cloud のアーキテクチャ検討
- 構成図作成、技術要件整理、非機能要件検討
- 概算見積もり
- 提案書の技術パート作成
- 顧客向けの技術説明

#### Areas

新規システム開発 / 生成 AI 活用 / 基幹システム刷新 / 食品・製造・公共領域の提案 / 自社 SaaS 提案 / OSS ベースの業務アプリ基盤
